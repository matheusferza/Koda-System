# 🚀 KODA_SYSTEM

Sistema desenvolvido em Python com interface gráfica para gerenciamento de etiquetas, banco de dados e automação de processos internos.

O projeto foi criado com foco em organização, produtividade e facilidade de uso, oferecendo uma solução prática para gerenciamento e impressão de etiquetas com suporte a banco de dados e personalização visual.

---

# 📸 Funcionalidades

✅ Interface gráfica moderna  
✅ Gerenciamento de banco de dados  
✅ Geração de etiquetas com código de barras  
✅ Organização de dados empresariais  
✅ Sistema de temas e estilização  
✅ Scripts para build e geração de instaladores  
✅ Estrutura modular para manutenção e escalabilidade  

---

# 🛠️ Tecnologias Utilizadas

- Python 3
- Tkinter / CustomTkinter
- SQLite
- Pillow
- Barcode
- PyInstaller
